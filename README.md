# FlexCrediAPP

FlexCredi es una aplicación móvil para la gestión de préstamos personales, clientes y cobros. Permite registrar préstamos y pagos, consultar historiales y reportes, y dar seguimiento a la cartera desde una interfaz sencilla.

## Tecnologías utilizadas

- Ionic 8
- Angular 20
- Capacitor 8 para Android e iOS
- Ionic Storage
- Leaflet para mapas
- Plugins de Capacitor para cámara, geolocalización, red, teclado, barra de estado y vibración
- Plugins para Bluetooth LE, lectura de códigos QR y códigos de barras, y NFC

## Instalación

Antes de comenzar, asegúrate de tener instalados [Node.js](https://nodejs.org/) y la CLI de Ionic.

```bash
npm install -g @ionic/cli
git clone https://github.com/Personalizadosmc/FlexCrediAPP.git
cd FlexCrediAPP
npm install
ionic serve
```

Después de ejecutar `ionic serve`, la aplicación se abrirá en el navegador para su uso y desarrollo local.
